# Feature Specification: 新特徵 A/B——股利事件特徵

**Feature Branch**: `chore/oct-review-batch`

**Created**: 2026-10-13

**Status**: 已量測，結論為回退（見 tasks.md）

**Input**: `OPTIMIZATION_PLAN.md` WP2.4 子項 1。除權息因子表（spec 017）已有每檔的除權息日與參考價比，
幾乎零成本就能衍生股利事件特徵；以同資料快照 A/B 判定是否採用。

## 背景與問題

四類模型（方向 / 風險 / 排序 / 下手）共用同一組特徵，其中沒有任何股利資訊。台股的填息行情、
高殖利率股的防禦性是市場上常被引用的型態，而資料已經在手上。

三次擴充特徵的嘗試（point-in-time 基本面、Qlib Alpha158、選擇權 P/C）都沒有讓主池的排序力過門檻，
所以本案**不預設會有效**：以量測為準，沒有改善就回退，不留在特徵集裡增加維護成本。

子項 2（新聞情緒）、子項 3（P/C 細項、VIX）不在本期範圍。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 以同一份資料判定特徵去留 (Priority: P1)

維運者加入股利事件特徵後，能在同一個資料截止日上對照加入前後的模型指標，並依事先講定的
規則決定採用或回退，而不是憑感覺留下。

**Why this priority**: 特徵集是訓練與線上共用的單一來源，每多一欄就多一份兩端同步的義務。
沒有量測依據的欄位只會累積成本。

**Independent Test**: 在固定截止日各跑一次評估快照（加入前 / 加入後），產出逐指標差異表，
依回退規則得出明確結論。

**Acceptance Scenarios**:

1. **Given** 加入前後兩份同截止日的快照，**When** 對照，**Then** 得到各模型各窗的指標差異表。
2. **Given** 主指標未改善且穩定度未提升，**When** 套用回退規則，**Then** 特徵自訓練與線上兩端一併移除，
   並留下量測紀錄。
3. **Given** 主指標改善，**When** 採用，**Then** 訓練與線上兩端對同一檔同一天算出相同的特徵值。

### Edge Cases

- 從未配息、或因子表沒有紀錄的個股：特徵為空值，不得以 0 代替（0 代表「剛除息」）。
- 訓練端回看歷史某一天時，只能使用**該日或之前**已發生的除權息事件。
- 尚未發生的除權息日（即使已公告）不得使用——因子表沒有公告日，用了就是偷看未來。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系統 MUST 能為任一檔個股的任一交易日算出：距最近一次除權息已過幾天、
  近一年累計除權息幅度（以參考價比推得的殖利率近似值）。
- **FR-002**: 特徵 MUST 只使用該交易日或之前已發生的除權息事件（point-in-time，憲章 IV）。
- **FR-003**: 訓練端與線上端 MUST 由同一份計算邏輯產生這兩個特徵，並有測試釘住兩端一致。
- **FR-004**: 採用與否 MUST 以同一資料截止日的前後對照決定。主指標為**小型股帶 5 日排序力**
  （目前唯一有實質排序力的模型），輔以主池排序力與風險模型辨識力。
- **FR-005**: 回退規則 MUST 事先明定：主指標差異 ≤ 0 且穩定度（ICIR）未提升 → 回退。
- **FR-006**: 回退時 MUST 自訓練與線上兩端同時移除，並保留量測結果作為紀錄。

### Key Entities

- **股利事件特徵**：`距最近除權息天數`、`近一年除權息幅度`；每檔每日一組，可為空。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 產出一份同截止日的前後對照表，涵蓋四類模型的各窗指標與小型股帶指標。
- **SC-002**: 依 FR-005 得出「採用」或「回退」的明確結論並記錄。
- **SC-003**: 若採用，訓練與線上對同一檔同一天的特徵值完全一致。
- **SC-004**: 不論結論為何，既有測試全數通過，晨報產出不受影響。

## Assumptions

- 因子表只有除權息日、沒有公告日，所以只做「回看」型特徵；「距下次除息還有幾天」需要公告日資料，
  不在本期。
- 因子表目前漏掉大比例配股、分割與減資（因子落在合理範圍檢查之外被丟棄，2026-10-13 發現）。
  這不影響本案特徵的定義，但表示對照用的基線本身帶有未還原的離群值；結論應以「此基線下」理解。
- 2026-10-13 的選股歸因顯示最終名單輸贏主要由候選池決定，而非模型排序。即使本案特徵有效，
  也只會改善候選內部的排序，不會改變候選池。
